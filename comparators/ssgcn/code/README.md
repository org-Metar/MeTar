# SSGCN comparator

PyTorch implementation of SSGCN, adapted from the authors' code at https://github.com/boyuezhong/SSGCN/. The Apache 2.0 license is retained in `LICENSE`.

`code/model.py` and `code/utils.py` supply the model and data helpers. The manuscript comparison uses the released selected score cache.

Use the repository's comparator environment and scientific reproduction commands in [Reproduction](../../../docs/reproduction.md). Large comparator inputs and checkpoints are downloaded with the published artifacts.
